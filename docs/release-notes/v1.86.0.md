**Português**
- Novo: **formato de dicionário v2**, que aumenta o limite do arquivo de dicionário de 4 MB para **16 MB**. O limite antigo estava quase cheio nos três dicionários (88% a 90% do espaço), o que impedia colocar mais palavras e mais pares de palavras. Nenhum dicionário muda nesta versão: os pacotes atuais (pt-BR 5, en-US 4, es 3) continuam no formato antigo e funcionam como antes. A mudança abre caminho para os próximos dicionários, maiores, que virão pelo download em Configurações → Sugestões e dicionários.
- Melhorado: o teclado lê os dois formatos (o antigo e o v2) no leitor nativo de dicionário, no motor nativo de correção e na versão de reserva em Java. O formato é reconhecido pelo cabeçalho do arquivo; um arquivo v2 com defeito (cortado ou com endereço fora do arquivo) é recusado em vez de travar ou mostrar sugestões erradas.
- Melhorado: o app só instala um pacote v2 se ele for novo o bastante para lê-lo. Quem ficar numa versão anterior à 1.86.0 mantém o pacote que já tem e vê o aviso de que o pacote precisa de uma versão mais nova do app; nada é apagado nem quebra.
- Melhorado: a velocidade de cada tecla não muda com o novo formato. Com os mesmos três dicionários convertidos para v2, a diferença na média ficou entre -2% e +4% (dentro do ruído da medição no computador) e o motor visita os mesmos nós. O dicionário continua mapeado em memória, sem cópia na memória do app, então um arquivo maior não aumenta o uso de memória do app nem o tempo de abertura de forma perceptível.
- Observações: o mesmo conteúdo ocupa cerca de 0,7 MB a mais no formato v2 (por volta de 19%), por causa dos endereços maiores; por isso o formato só vale a pena para dicionários que realmente passam de 4 MB. Os arquivos de trigramas (`trigrams.bin`) não mudam. O tempo de abertura com um pacote de 16 MB em um aparelho de entrada só pode ser medido num aparelho de verdade e está na lista de conferência da versão.

**English**
- New: **dictionary format v2**, which raises the size limit of the dictionary file from 4 MB to **16 MB**. The old limit was almost full in all three dictionaries (88% to 90% of the space), which stopped us from adding more words and more word pairs. No dictionary changes in this version: the current packs (pt-BR 5, en-US 4, es 3) stay in the old format and work as before. The change opens the way for the next, larger dictionaries, which will arrive through the download in Settings → Suggestions and dictionaries.
- Improved: the keyboard reads both formats (the old one and v2) in the native dictionary reader, in the native correction engine and in the Java fallback. The format is recognised by the file header; a damaged v2 file (cut short or with an address outside the file) is refused instead of crashing or showing wrong suggestions.
- Improved: the app installs a v2 pack only if it is new enough to read it. Anyone on a version older than 1.86.0 keeps the pack they have and sees the notice that the pack needs a newer version of the app; nothing is deleted and nothing breaks.
- Improved: the speed of each key press does not change with the new format. With the same three dictionaries converted to v2, the difference in the average was between -2% and +4% (within the noise of the measurement on a computer) and the engine visits the same nodes. The dictionary is still memory-mapped, with no copy in the app's memory, so a bigger file does not noticeably increase the app's memory use or the opening time.
- Notes: the same content takes about 0.7 MB more in format v2 (around 19%), because of the wider addresses; so the format only pays off for dictionaries that really go over 4 MB. The trigram files (`trigrams.bin`) do not change. The opening time with a 16 MB pack on a low-end phone can only be measured on a real device and is on the checklist of this version.
