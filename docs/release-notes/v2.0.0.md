**Português**
- Novo: **Ctrl + apagar apaga por palavra**: com o Ctrl ativo, a tecla apagar remove uma palavra por toque e, segurando, apaga palavra por palavra desde o início. Ative em **Configurações → Toque e gestos**, ao lado de **Duração do toque longo**, e ajuste o intervalo entre as palavras para soltar na hora certa.
- Corrigido: O toque longo de uma tecla (como o 123) vinha mais tarde que o tempo definido quando o teclado recebia o toque com atraso; agora o tempo conta a partir do toque.
- Melhorado: Em **Configurações → Avançadas → Desempenho**, **Tempos do teclado** mostra o pior toque longo e onde o tempo foi.
- Como receber: Instale o aplicativo 2.0.0 ou vá em **Configurações → Sobre → Procurar atualização**.

**English**
- New: **Ctrl + delete deletes by words**: with Ctrl on, the delete key removes a word per tap and, when held, deletes word by word from the start. Turn it on in **Settings → Touch and gestures**, next to **Long-press duration**, and set the interval between words to let go at the right moment.
- Fixed: The long press of a key (like 123) came later than the set time when the keyboard got the touch late; the time now counts from the touch.
- Improved: In **Settings → Advanced → Performance**, **Keyboard times** shows the worst long press and where the time went.
- How to get it: Install app 2.0.0 or go to **Settings → About → Check for updates**.
