**Português**
- Novo: o arquivo dos **trios de palavras** (`trigrams.bin`) ganhou um formato mais compacto, o **MRT2**. Ele fica **24 a 26% menor** (pt-BR 4,70 → 3,56 MB, en-US 4,72 → 3,49 MB, es 4,93 → 3,78 MB), e cada pacote ficou **cerca de 5% menor para baixar** (pt-BR 6,72 → 6,39 MB, en-US 6,59 → 6,24 MB, es 6,73 → 6,42 MB) e **cerca de 10% menor no aparelho** (pt-BR 10,97 → 9,82 MB). A folga até o limite de 7 MB de download do pacote subiu de 0,28 para 0,61 MB no pt-BR.
- Mesmo conteúdo, mesmas sugestões: os pacotes novos (**pt-BR 8, en-US 7, es 6**) têm exatamente os mesmos trios dos anteriores, só escritos de outro jeito. No PC, cerca de 550 mil consultas por idioma deram o mesmo resultado nos dois formatos e coincidem com uma leitura feita à parte.
- Memória: a biblioteca nativa agora **mapeia o arquivo** em vez de copiá-lo. Antes, cada idioma ativo mantinha cerca de 6 MB na memória do aplicativo (o arquivo inteiro mais 1,2 MB de índices montados na abertura). Agora o MRT2 não monta índice nenhum e as páginas do arquivo são as do próprio sistema, que pode descartá-las quando precisar de memória. A troca de pacote continua segura: o instalador grava a versão nova em outra pasta e apaga a velha, nunca regrava um arquivo aberto (há teste que troca o pacote com o arquivo aberto).
- Abertura no PC: de cerca de 3 ms para 0,5 ms, e a busca do trio de 0,9–1,0 µs para 0,7–0,8 µs. Esses números são do PC; **não foram medidos em um aparelho de verdade**.
- Novo na tela **Configurações → Sugestões e dicionários**: a linha **Memória dos dicionários** mostra, para o idioma em uso, o tamanho do dicionário e dos trios, quanto de cada um está na memória agora, quanto tempo levou para abrir e quanto o motor levou para iniciar. É o jeito de obter números de um aparelho real.
- **Importante:** os pacotes MRT2 só funcionam no aplicativo 1.90 ou mais novo (`minApp` 1090000). Quem tem uma versão anterior continua com os pacotes que já tem (pt-BR 7, en-US 6, es 5) e a tela não oferece a atualização dos pacotes até o aplicativo ser atualizado. O aplicativo 1.90 ainda lê os pacotes antigos (MRT1).
- Como receber: instale o aplicativo 1.90.0 e vá em **Configurações → Sugestões e dicionários → Verificar atualizações**.
- Por baixo: biblioteca nativa nova (o motor lê MRT1 e MRT2), instalador do aplicativo aceita os dois formatos, ferramentas para converter e comparar os dois (`docs/tools/convert_trigrams.py`) e testes novos (formato, arquivos corrompidos, troca de pacote com o arquivo aberto, ASan/UBSan).

**English**
- New: the file of **word triples** (`trigrams.bin`) has a more compact layout, **MRT2**. It is **24 to 26% smaller** (pt-BR 4.70 → 3.56 MB, en-US 4.72 → 3.49 MB, es 4.93 → 3.78 MB), and each pack is **about 5% smaller to download** (pt-BR 6.72 → 6.39 MB, en-US 6.59 → 6.24 MB, es 6.73 → 6.42 MB) and **about 10% smaller on the device** (pt-BR 10.97 → 9.82 MB). The room left under the 7 MB download limit of a pack went from 0.28 to 0.61 MB for pt-BR.
- Same content, same suggestions: the new packs (**pt-BR 8, en-US 7, es 6**) have exactly the same triples as the previous ones, only written differently. On the PC, about 550 thousand queries per language gave the same result in both layouts and match a separate reading of the data.
- Memory: the native library now **maps the file** instead of copying it. Before, each active language kept about 6 MB in the app's memory (the whole file plus 1.2 MB of indexes built at open). Now MRT2 builds no index at all and the pages of the file belong to the system, which can drop them when it needs memory. Swapping a pack is still safe: the installer writes the new version in another folder and deletes the old one, it never rewrites an open file (a test swaps the pack with the file open).
- Opening on the PC: from about 3 ms to 0.5 ms, and the triple lookup from 0.9–1.0 µs to 0.7–0.8 µs. These are PC figures; they were **not measured on a real device**.
- New on **Settings → Suggestions and dictionaries**: the **Dictionary memory** line shows, for the language in use, the size of the dictionary and of the triples, how much of each is in memory now, how long it took to open and how long the engine took to start. It is the way to get figures from a real device.
- **Important:** MRT2 packs only work on app 1.90 or newer (`minApp` 1090000). Anyone on an earlier version keeps the packs they have (pt-BR 7, en-US 6, es 5) and the screen does not offer the pack update until the app is updated. App 1.90 still reads the old packs (MRT1).
- How to get it: install app 1.90.0 and go to **Settings → Suggestions and dictionaries → Check for updates**.
- Under the hood: new native library (the engine reads MRT1 and MRT2), the app's installer accepts both layouts, tools to convert and compare them (`docs/tools/convert_trigrams.py`) and new tests (layout, corrupt files, swapping a pack with the file open, ASan/UBSan).
