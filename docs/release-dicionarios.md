Pacotes de dicionário do Mr Keyboard. Baixe pelo app: *Configurações → Dicionários* (a partir da 1.63). Não é preciso baixar nada daqui à mão.

Mr Keyboard dictionary packs. Download them in the app: *Settings → Dictionaries* (from 1.63 on). There is no need to download anything here by hand.

- `catalogo.json`: lista dos pacotes, assinada com a chave do app / pack list, signed with the app's key
- `<idioma>-<versão>.zip` / `<language>-<version>.zip`: um pacote / one pack

O app só baixa quando você toca em *Baixar*. Nada do que você digita é enviado.
The app only downloads when you tap *Download*. Nothing you type is ever sent.
