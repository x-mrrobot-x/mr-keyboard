Source: https://huggingface.co/futo-org/futo-swipe, revision 315d42583233b71d75665d076cfa2f2c7c6f43ad,
file honorable_sturgeon/model_fp32.pte (SHA-256 725242bab5d14345e96ff214e8de2bfbc1f962c232d320df9c24cb82ffd1fbaf).

The weights were not modified. They were taken out of the ExecuTorch container (.pte) and written, tensor by tensor and
byte for byte, into a plain container that the Mr Keyboard engine reads (it starts with MRSWENC1). The tool that does it,
and that checks a file against the published one, is docs/tools/gesture/extract_weights.py in the Mr Keyboard repository.

The licence covers the weights only. The code that runs the network (engine/src/mr_gesture_nn.cpp in the Mr Keyboard
repository) was written for Mr Keyboard and is under the Apache License 2.0; it uses none of FUTO's inference code.

Mr Keyboard shows, in Settings > Suggestions and dictionaries > Gesture typing, the notice the licence asks for: gesture
typing in the app is powered by "FUTO Swipe" technology.
